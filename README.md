# 📚 Friend Study Buddy

> A simple, clean, and interactive study companion website built for students and friends using **HTML**, **CSS**, and **Vanilla JavaScript**.

---

## 🚀 Features

1. **Study Planner**: Dynamically calculates a balanced breakdown (concept theory, examples, practice questions, revision, and testing) based on the user's selected study duration and difficulty.
2. **Quick CS Quiz**: 5 interactive multiple-choice questions testing fundamental Computer Science concepts with automatic score calculation and personalized feedback.
3. **Quick Revision Notes**: Instant flash summaries for **HTML**, **CSS**, **JavaScript**, and **DSA**.
4. **Motivational Quotes Generator**: Over 10 inspiring study affirmations with random quote generation.
5. **Dark Mode Toggle**: Toggle between light and dark themes using CSS variables and clean DOM manipulation.
6. **Fully Responsive**: Adapts seamlessly to mobile, tablet, and desktop screens.

## 💻 How to Run Locally

Since this project uses only pure HTML, CSS, and Vanilla JavaScript (no backend, no database, no npm build step required):

### Method 1: Direct File Open (Easiest)
1. Navigate to the `friend-study-buddy` folder on your computer.
2. Double-click `index.html` to open it directly in any web browser (Chrome, Edge, Firefox, Safari).

### Method 2: VS Code Live Server
1. Open the `friend-study-buddy` folder in **Visual Studio Code**.
2. Install the **Live Server** extension (by Ritwick Dey).
3. Right-click `index.html` and click **"Open with Live Server"**.

---

## 🌐 How to Host on GitHub Pages (Free)

1. Create a new repository on [GitHub](https://github.com) named `friend-study-buddy`.
2. Push your project files (`index.html`, `style.css`, `script.js`, `README.md`) to the `main` branch.
3. In your GitHub repository, go to **Settings** > **Pages** (in the left sidebar).
4. Under **Branch**, select `main` and root folder `/`, then click **Save**.
5. After 1–2 minutes, your live site URL will appear at:
   `https://<your-username>.github.io/friend-study-buddy/`
